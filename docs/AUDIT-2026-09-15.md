# Audit dan perbaikan — 15 September 2026

## Ringkasan

Audit mencakup kode backend, frontend, kontrak WebSocket, query graf, sumber data,
dependensi, pengalaman pengguna, konfigurasi, dan pengujian. Perbaikan diterapkan langsung
pada repositori lokal. Database dan berkas sumber Al-Qur'an tidak diubah atau di-ingest ulang.

Masalah terpenting adalah pengiriman kredensial database ke browser, kemungkinan sumber
bercampur antarcabang tematik, percakapan macet ketika koneksi putus, serta jawaban lama
yang menggunakan daftar sumber pertanyaan terbaru. Semua alur tersebut telah diperbaiki.

## Batas hasil dan peningkatan berikutnya

1. **Integrasi nyata belum diverifikasi.** Keenam konfigurasi wajib belum tersedia:
   OpenAI key, Pinecone key/nama indeks, dan URI/user/password Neo4j. Setelah diisi,
   jalankan pertanyaan acuan dan periksa model embedding, namespace, isi indeks,
   hak baca database, hasil query, serta waktu proses. Tidak ada API berbayar dipanggil dalam tes.
2. **Akurasi semantik belum diukur.** Siapkan kasus acuan yang ditinjau orang kompeten,
   mencakup tema mudah, sinonim, negasi, nama nabi, pertanyaan lintas tema, serta pertanyaan
   yang tidak bisa dijawab. `evaluate.py` siap menghitung metrik, tetapi audit ini tidak
   mengarang baseline atau mengklaim peningkatan recall.
3. **Ranking ayat masih terbatas.** Pinecone meranking jalur; ayat di dalam jalur diurutkan
   secara numerik dan dibatasi 25. Pemilihan bergilir memperluas cakupan tema, tetapi ayat
   relevan setelah batas itu bisa terlewat. Bandingkan reranking ayat atau lexical retrieval
   dengan baseline sebelum menambah biaya/kompleksitas; jangan menetapkan threshold skor
   secara sembarang tanpa evaluasi indeks yang digunakan.
4. **Pemeriksaan sitasi bukan pemeriksaan makna.** Sitasi yang menunjuk ID valid tetap bisa
   menyertai ringkasan yang kurang tepat. Diperlukan evaluasi kesetiaan jawaban terhadap ayat
   dan peninjauan manusia; validasi ID tidak membuktikan kutipan atau tafsir benar.
5. **Delapan referensi sumber perlu koreksi manual.** Setelah terverifikasi, perbarui sumber,
   indeks, dan graf melalui proses yang dapat ditelusuri. Schema graf berbasis nama masih
   dipertahankan untuk kompatibilitas; katalog jalur menjadi pengaman. Migrasi ke node tema
   ber-ID jalur merupakan pilihan jangka panjang yang memerlukan rencana migrasi data.
6. **Deployment publik memerlukan autentikasi dan pembatasan terpusat.** Profil demo dan
   Origin bukan login server. Rate limit saat ini per proses/per alamat klien; beberapa
   worker atau proxy membutuhkan konfigurasi identitas klien dan kuota bersama. Gunakan
   HTTPS/WSS, akun Neo4j baca saja, batas koneksi proxy, serta monitoring biaya/latensi.
7. **Riwayat bersifat lokal dan pertanyaan diproses mandiri.** 40 pesan terakhir disimpan
   pada sesi tab; isi percakapan sebelumnya tidak otomatis masuk prompt. Referensi ambigu
   seperti “ayat tadi” belum memiliki resolusi konteks multigilir. Penambahannya perlu
   desain batas konteks dan evaluasi agar sumber antarpesan tetap benar.

## Rujukan teknis

Penggunaan parameter dan sesi baca mengacu pada dokumentasi
[Neo4j Python Driver](https://neo4j.com/docs/python-manual/current/query-simple/).
Pengelolaan koneksi Pinecone memakai context manager async agar sesi ditutup saat selesai
atau dibatalkan, sesuai [dokumentasi SDK Pinecone](https://docs.pinecone.io/reference/sdks/python/overview).
Transport dan penutupan WebSocket mengikuti [FastAPI WebSockets](https://fastapi.tiangolo.com/advanced/websockets/).
Peta memakai API Network dan lifecycle destroy/fit dari
[vis-network](https://visjs.github.io/vis-network/docs/network/).
